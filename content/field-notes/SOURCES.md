# Field Notes Source Watchlist

Organized by desk, matching the 13 categories in `lib/fieldNotesTaxonomy.ts`.
See `EDITORIAL_SYSTEM.md` for the tier system (primary / institutional /
trade media / discovery-only) these sources sit in. Discovery-only sources
(general news, newsletters, social, aggregators) are omitted here on
purpose, use them to find stories, never to source a figure.
